# Project Plan

This file tracks the Week 0–Week 12 execution plan for the AI Technology Consulting Readiness Dashboard.

The full task checklist is managed on the GitHub Issues board (see the milestone list for each week).

## Milestones

| Milestone | Goal |
|---|---|
| Week 0 | Infrastructure live, team roles confirmed, sample companies added |
| Week 1 | 10–15 companies in dataset, scoring rubric drafted, first wireframe done |
| Week 2 | 20+ companies, first scoring pass on 10 companies, scoring issues identified |
| Week 3 | Scoring framework v0.2 published, consistency check passed, all wireframes approved |
| Week 4 | Power BI connected to real data, first 2 dashboard pages built and screenshotted |
| Weeks 5–6 | 35–50 companies, AI summaries and recommendations reviewed and added |
| Weeks 7–8 | SQL schema committed, data dictionary complete, GitHub README finalized |
| Weeks 9–11 | Final dashboard complete, consulting report written, demo script prepared |
| Week 12 | Final polish, GitHub finalized, demo practiced, Version 1 complete |
